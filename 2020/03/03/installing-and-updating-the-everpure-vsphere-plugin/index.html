Installing and Updating the Everpure vSphere Plugin

March 3, 2020 · 3 min read · 507 words
Share

Welcome to the first of many Everpure blogs. As I get ramped up with the latest information I plan to do a series of getting started with Everpure features. These blogs will cover things such as the vSphere Client (HTML5) Plugin, FlashArray, FlashBlade and integrations with other VMware products. First up is learning to install and update the Everpure vSphere Client Plugin.

In this post we will cover how to install and update the vSphere Plugin using Powershell and PowerCLI. You could install the plugin using the Everpure UI, however why not use some automation?.

At the time of writing, the latest vSphere Plugin is version 4.2.0. However, because the array is running older code only 4.0.0 is available. If you want to get a newer version of the plugin you can contact Everpure Support and they can push the newer version to your array. This means that I am unable to use the latest version of the plugin even though it is compatible if I do not get it updated.

Installing the Everpure Powershell Module#

The Everpure Powershell Module for VMware is located in the Powershell Gallery and can be installed by running the following command

Install-Module -Name PureStorage.FlashArray.VMware

It’s that easy!

Installing the Everpure vSphere Plugin#

Once you have the Everpure module isntalled, we can connect to the vCenter Server we wish to install the plugin to and run the Install-PfavSpherePlugin cmdlet to install it. If we wanted to, we could actually install a previous version.

To see versions available to install run:

Get-PfavSpherePlugin -html -previous

We see here that 4.2.0 is the latest but since we plan to perform an upgrade i will install version 4.1.0. See the below snippet on how to connect to vCenter Server and install the vSphere Plugin.

4.2.1 shows up under previous, even though it is a “newer” version it is not certified which is why it does not qualify to be the latest build.

Connect-VIServer vcsa03.newstack.local -User administrator@vsphere.local -Password VMware1!
Install-PfavSpherePlugin -version 4.1.0

Updating the Everpure vSphere Plugin#

To update the vSphere Plugin its the exact steps as the installation, you just specify no version (use the latest) or a newer version. Here i have left version empty so it will install the latest version which is 4.2.0.

Connect-VIServer vcsa03.newstack.local -User administrator@vsphere.local -Password VMware1!
Install-PfavSpherePlugin

Verifying the Everpure vSphere Plugin Installed#

When we login to the vSphere Client you will see the Plugin has been installed but must be refreshed to be loaded. When the browser has been refreshed, we can see that the Everpure plugin has been installed and is pending configuration.

Uninstalling the Everpure vSphere Plugin#

Just in case you want to uninstall the Plugin, you can use the vCenter Server MOB or use the below Powershell cmdlet.

Connect-VIServer vcsa03.newstack.local -User administrator@vsphere.local -Password VMware1!
Uninstall-PfavSpherePlugin
